# Data sources

- Bigdata.com MCP: primary. See [[How to - Pull Bigdata Sentiment]] and [[Bigdata Query Cookbook]]
- DefiLlama: TVL, stablecoin supply, fees
- Token Terminal: protocol fees, active users (Uniswap, Robinhood Chain)
- Santiment: on-chain fee and activity data
- Lookonchain: whale flows, weekly stablecoin report
- L2BEAT: L2 metrics
- Stocktwits: retail sentiment zones (neutral/bullish/bearish) and chatter level
